# 🃏 War Card Game - iOS App

Welcome to my very first iOS project! 🎉  
This is a simple yet functional mobile version of the classic **War** card game, built entirely in Swift using UIKit (or SwiftUI, depending on what you used). The game pits two players against each other in a battle of luck and cards.

## 📱 Features

- Two-player automated gameplay (you vs. computer)
- Classic War card rules implemented
- Clean and minimal UI
- Real-time score updates
- Fun and replayable gameplay loop

## 🚀 Getting Started

To try it out locally:

1. Clone the repo:
   ```bash
   git clone https://github.com/your-username/war-card-game-ios.git
Open the .xcodeproj or .xcworkspace file in Xcode.

Build and run the app on the iOS Simulator or your own device.

🎮 Gameplay
Tap a button to draw a card for each player.

The higher card wins the round and scores a point.

Ties initiate a "war" round — more cards are drawn!

The game continues until the deck runs out.

🔧 Tech Stack
Language: Swift

Platform: iOS

Framework: UIKit / SwiftUI

Tools: Xcode
